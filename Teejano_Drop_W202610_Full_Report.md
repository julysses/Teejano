## POSTMORTEM FRAMEWORK

### Weekly Evaluation Checklist (Run Every Monday — 7 Days Post Drop)

**Performance Thresholds**

| metric | winner | watch | cut |
|---|---|---|---|
| CTR (organic) | ≥ 3.5% | 1.5–3.4% | < 1.5% |
| Conversion Rate | ≥ 3.0% | 1.0–2.9% | < 1.0% |
| ROAS (paid) | ≥ 3.5x | 2.0–3.4x | < 2.0x |
| ATC Rate | ≥ 8.0% | 4.0–7.9% | < 4.0% |
| Units Sold (7 days) | ≥ 15 | 5–14 | < 5 |

**Winner Detection Rules**
- If units ≥ 15 AND conversion_rate ≥ 3.0% within 7 days → flag as `hot_winner` → reorder immediately → increase ad budget 2x
- If units ≥ 8 AND roas ≥ 3.5x → flag as `paid_winner` → scale Meta/TikTok spend
- If organic shares/saves ≥ 2x average → flag as `viral_candidate` → push organic content hard this week

**Phrase Blacklist Auto-Add Rules**
Add phrase to `phrase_blacklist` table if any of the following:
- 3+ customer reports of similarity to existing mark → `status: trademark_risk`
- 0 purchases in 14 days AND > 500 impressions → `status: market_rejected`
- Guardian score < 70 on re-evaluation → `status: quality_rejected`
- Concept uses phrase from blacklist in any variation → `status: blocked_at_ideation`

**Future Ideation Prioritization**
- Week N+1: Always include ≥ 1 concept in same category as `hot_winner` from Week N
- City-specific concepts: rotate cities, never repeat same city two consecutive drops
- Seasonal concepts: flag seasonality field in ideation and schedule campaign timing accordingly
- Bilingual concepts: track separately — if bilingual variant outperforms base phrase, increase Spanglish production in subsequent drops
- Low Guardian Score categories (scored < 84): reduce allocation in next drop, brief for stronger hook
